# Attribute useful paid usage

Use optional `X-SafeRoute-Source` and `X-SafeRoute-Application` headers with non-personal labels. Set the source only to the channel actually used, such as `github-skill` or `merit-awesome`; do not infer discovery from an installed package. Omit unknown source or application. Labels are self-reported, not verified identities. Never include emails, names, secrets or prompt contents in labels.

For each channel, measure independently: visible listing; schema/skill inspection; first verified paid request; received usable result; repeat independent paid use on later dates; voluntary operator explanation. An installation, request ID or wallet does not prove company identity or unique agent ownership.

The API supplies an optional feedback URL. Let an operator choose whether to submit use case, reason for returning, source, expected volume, product gaps and price fit. Contact details and follow-up consent are voluntary; feedback does not authorize unsolicited outreach. Keep private contacts outside public issues and analytics.

Compare receipts and attributable costs over matching dates. Hosting, RPC/provider/facilitator charges, refunds, partner fees and support matter. Revenue is not profit. Do not buy traffic or manufacture paid calls to improve rankings. Continue with the smallest useful experiment and unchanged acquisition spending.
